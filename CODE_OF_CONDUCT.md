# Code of Conduct

Citadail contributors are expected to keep collaboration respectful, direct, and constructive.

## Expected Behavior

- Be kind and professional.
- Assume good intent while still being clear about problems.
- Give actionable feedback.
- Respect different backgrounds, skill levels, and viewpoints.
- Keep discussions focused on improving the project.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without permission.
- Repeated disruptive behavior.
- Spam or bad-faith participation.

## Reporting

Report conduct concerns to the project maintainers through the repository's private contact path or GitHub moderation tools.

Maintainers may remove comments, close issues, block users, or take other reasonable action to protect the project community.
